# Logo sources

- TUM: official logo geometry from https://www.tum.de/typo3conf/ext/in2template/Resources/Public/Images/Backend/tum-logo.svg, displayed in navy on a transparent background.
- Bilkent University, Saarland University and Karşıyaka Atakent Anatolian High School: existing logo files supplied with this portfolio.
